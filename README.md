# 💬 Mini Chat System

A beginner-friendly **Mini Chat System** built using Python and Object-Oriented Programming (OOP).

This project simulates a group chat where multiple users can join a chat room, send messages, view chat history, and leave the room.

## ✨ Features

- Add users to a chat room.
- Send messages between users.
- Assign unique message IDs.
- Display complete chat history.
- Allow users to leave the chat room.

## 🛠️ Technologies Used

- Python
- Object-Oriented Programming (OOP)
- Jupyter Notebook

## ▶️ How to Run

1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Open `chat_system.ipynb`.
4. Select a Python kernel.
5. Click **Run All** to execute the notebook cells.
6. View the output below the code cells.
